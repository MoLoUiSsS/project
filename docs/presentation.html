OCR

Lecture de plaques algériennes

🖼️ Preprocessing OpenCV

1 Upscale → min. 800px (INTER_LANCZOS4)
2 Conversion Grayscale
3 CLAHE — contraste adaptatif local (clipLimit=3.0)
4 Filtre bilatéral — débruitage sans flou
5 Sharpening — kernel Laplacien 3×3

🔤 Format Plaque Algérienne

53872 100 16
Numéro (4-6 ch.) Milieu (2-3 ch.) Wilaya (01-58)

Corrections OCR : O→0, I→1, S→5, B→8, G→6, T→7, A→4

🔄 Stratégie Multi-Fallback

① Image améliorée — OCR Engine 2
Meilleur pour les polices, plus rapide
↓ si échec
② Image améliorée — OCR Engine 1
OCR classique basé sur Tesseract cloud
↓ si échec
③ Image originale — Engine 2 + 1
Sans preprocessing, au cas où il nuisait
↓ si échec
④ Tesseract local — hors ligne
Fallback offline — fonctionne sans internet
🔑 Rotation de 2 clés API + cooldown 1h si rate-limit

Défis Techniques

Problèmes rencontrés & solutions

Problème 1

Rate Limiting API OCR

Quota 429 après plusieurs captures rapides → OCR bloqué

Solution

Rotation de 2 clés API + blacklist temporaire 1h + fallback Tesseract local

Problème 2

HTTPS requis pour caméra

Chrome Android refuse getUserMedia sur HTTP externe

Solution

Tunnel Cloudflared gratuit → HTTPS valide + accès mondial + PWA manifest

Problème 3

Fausse déconnexion caméra

Fermer un onglet dashboard coupait la caméra du téléphone

Solution

Suivi du request.sid du téléphone — seule sa session peut déclencher la déconnexion

Problème 4

Chemins Windows (Backslash)

Images non affichées — os.path.join génère des \ au lieu de /

Solution

os.path.relpath() + replace(os.sep, '/') → chemins web corrects sur Windows & Linux

Problème 5

Captures multiples (rebond)

Le capteur oscillait autour de 30cm → plusieurs captures du même véhicule

Solution

Anti-rebond double : Arduino DEBOUNCE 5s + flag Python detection_cooldown 8s

Problème 6

OCR Mauvaise qualité

Plaques floues ou faible contraste → lecture incorrecte

Solution

Pipeline OpenCV : CLAHE + filtre bilatéral + sharpening + upscale 800px
